## 1.10.0（2026-11-27）改用工具組共用風格

### 起因
果實分配原本用 Bootstrap 原色（藍綠紅紫混在一起），頂部按鈕在手機上堆成三排、「全部初始化」和一般按鈕一樣大；浮動的復原、重做、GitHub、工具箱疊在內容上。

### 改了什麼
- 讀工具箱提供的共用風格 `/monster-strike-toolbox/theme.css`，本工具只設定強調色（綠）。
- 按鈕分三種：主要操作綠色實心；一般操作白底外框；危險操作紅色外框。快速分配的四個組合按鈕保留各自顏色方便分辨。
- 手機上復原、重做、GitHub、工具箱放在底部固定一列，頁面底部預留空間。
- 支援深色模式；表格表頭改淺色。
- 只改畫面：資料讀寫、登入、雲端同步、存檔切換都沒動。

### 怎麼驗證的
- 手機 375 寬、桌機 1280 寬，淺色、深色各截圖確認，沒有橫向捲動。
- 本機實際新增角色後出現在分配表、切換到英雄 BANK 分頁、按復原把角色移除、點工具箱展開清單、打開角色清單視窗，都正常。

### 已知限制
- 本機要用 Monster-Strike 資料夾當網站根目錄開，才讀得到共用風格。
- 手機版分配表的角色名稱列沿用原本的深灰底（深淺色都看得清楚）。

## 1.9.2（2026-11-27）防止首次上傳互蓋、錯誤提示

### 起因
代碼盤點發現：第一次登入時把本機存檔上傳雲端，是「先看雲端有沒有，沒有再寫」分兩步做。兩台裝置同時第一次登入，可能都以為雲端沒有，後寫的就蓋掉先寫的。其他存檔寫入早就用 transaction，只有這兩處例外。

### 改了什麼
- **首次上傳**：改在 transaction 裡檢查並寫入，雲端已有就不寫。
- **「發現本機存檔」上傳**：原本直接覆寫雲端；現在雲端已有同一份存檔時保留雲端版本，只把它加回存檔清單，並提示可先「下載備份」保存本機版本。
- **本機儲存失敗**（隱私模式、空間已滿）：讀不到當作沒資料，寫不進去跳一次提示，不再讓操作停在一半。
- **未預期的錯誤**：第一次跳提示視窗，之後只寫在主控台，避免連續彈窗。
- 開頁時先連線 Firebase 伺服器。

### 怎麼驗證的
- 本機實際新增角色，確認存進本機；模擬本機空間已滿時跳出「本機儲存失敗」提示；模擬未預期錯誤時跳出提示。

### 沒驗證的部分
- transaction 上傳需要登入雲端，本機沒有實測；寫法和既有的存檔寫入（`writeToCloud`）相同。上線後第一次登入新裝置時留意存檔是否正常出現。
